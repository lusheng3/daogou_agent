# daogou_agent

基于 Java 的电商导购 Agent 项目，用于完成一条可演示、可测评、可解释的导购主链路。

## 当前阶段

项目处于 Phase 0：项目基线与规范阶段。尚未开始业务代码实现。

## 技术基线

- Java 21
- Spring Boot 3.x
- Maven
- 模块化单体
- MySQL、Redis、Milvus
