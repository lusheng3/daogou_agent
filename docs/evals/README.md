# 测评目录

## 目录职责

- `cases/`：固定输入与预期结果。
- `datasets/`：商品、知识、对话和评分规则快照。
- `reports/`：各版本测评结果。

## 测评层级

### 单节点测评

- 记忆筛选。
- Query 改写。
- domain/action 分类。
- 工具参数。
- RAG 召回。

### 模块测评

验证模块完成自身职责，并能与上下游契约协作。

### 端到端测评

使用完整对话脚本验证最终商品、回答、引用和操作状态。

## 记录要求

每次正式测评必须记录：

- 代码提交。
- 模型版本。
- Prompt 版本。
- 数据集版本。
- 商品快照版本。
- 指标和失败案例。

未固定版本的结果不进入正式对比。
