# Platform Foundation Requirements

状态：Review

## 1. 目标

建立可启动、可测试、可观测的 Java 工程基础，为后续商品、会话、Agent 和 RAG 模块提供统一约束。

## 2. In Scope

- Java 21 Maven 工程。
- Spring Boot Web 应用。
- 基础包名和业务能力包结构。
- 本地与测试配置分离。
- 统一 API 错误结构。
- 请求 Trace ID。
- 健康检查。
- 数据库迁移基础设施。
- 本地基础设施编排。
- 单元测试和集成测试基础。
- 基础 README 和运行说明。

## 3. Out of Scope

- 商品业务表与查询逻辑。
- 会话和消息持久化。
- LLM Provider 实现。
- Agent Runtime。
- RAG 入库与检索。
- 购物车写入。
- 前端界面。

## 4. 输入与输出

### 输入

- HTTP 请求。
- 本地配置和环境变量。
- 可选的 `X-Trace-Id`。

### 输出

- 标准化 HTTP 响应。
- 标准化错误响应。
- `X-Trace-Id` 响应头。
- 健康检查结果。
- 可被自动化测试执行的 Maven 工程。

## 5. 行为要求

- 应用默认配置可启动。
- 未连接可选外部依赖时，基础单元测试仍可执行。
- 每个请求必须有 `trace_id`。
- 未处理异常必须转换为统一错误响应。
- 错误响应不能泄露堆栈、SQL、密钥或内部路径。
- 数据库迁移必须在启用数据库配置时执行。
- 健康检查能够区分应用存活与外部依赖状态。

## 6. 非功能要求

- 所有新增配置项有默认值或明确启动失败原因。
- 不在配置文件中保存明文密钥。
- 基础工程构建可重复。
- 测试不依赖开发者本地已有数据库状态。
- 代码结构为后续业务模块扩展预留边界。

## 7. 依赖

- Java 21。
- Maven。
- Spring Boot 3.x。
- MySQL 8。
- Redis 7.x。
- Docker 或兼容的容器运行时，用于本地基础设施。
